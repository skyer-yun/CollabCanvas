## 详细变更

### 1. main.js — appFacade 树形数据模型

**问题**：原 appFacade 使用 `{id, name, module, html}` 扁平结构，无法表达文件夹层级。`importPages` 直接替换画布内容，`switchPage` 不保存当前页。

**变更**：

- 新增辅助函数 `_uid()`、`_findNode(id)`、`_getChildIds(parentId)`、`_findFirstPage(nodes)`
- `_saveCurrentToPage()` — 改为通过 `_findNode` 查找节点并更新，支持树形结构
- `_loadPageToCanvas(page)` — 无改动，保持原有逻辑
- `addPage(name, parentId)` — 新增 `parentId` 参数，自动计算 `order`
- 新增 `addFolder(name, parentId)` — 创建文件夹节点
- 新增 `toggleFolder(id)` — 展开/折叠文件夹
- 新增 `moveNode(nodeId, newParentId, order)` — 拖拽移动，含循环引用检测
- `deletePage(id)` — 改为递归收集后代 ID，一并删除
- `switchPage(id)` — 增加类型检查（跳过 folder）
- `importPages(files)` — 新增 `_ensureFolder(pathParts)` 递归构建目录树

**数据模型变更**：

```
// 旧: { id, name, module, html, thumbnail, updatedAt }
// 新: { id, type, name, parentId, order, html, thumbnail, expanded, updatedAt }
```

**新增事件**：`page:toggled`、`page:moved`

**构造函数变更**：`new CCPagesTab(appFacade)` → `new CCPagesTab(appFacade, modal)`

### 2. ui/tabs/pages-tab.js — Axure 风格重写

**问题**：
1. CSS 布局在窄面板中文字竖排
2. "新建"按钮无响应（`window.CCModal` 是构造函数不是实例）
3. 导入替换当前页面
4. 文件夹导入不显示树形结构
5. 需要类似 Axure/IDE 的文件树管理

**变更**：

- 构造函数接收 `modal` 实例：`PagesTab(app, modal)`
- 工具栏改为紧凑单行布局（图标按钮 + 内联搜索框）
- 树形渲染：`_renderLevel(parentEl, items, allPages, depth)` 递归缩进
- 文件夹行 `_createFolderRow(folder, depth, allPages)`：展开箭头 + 文件夹图标 + 名称 + 计数
- 页面行 `_createPageRow(page, depth)`：页面对齐占位 + 图标 + 名称 + 悬停操作
- 右键菜单 `_showContextMenu(x, y, id)`：新建子项/重命名/删除
- 拖拽：`_moveInto(srcId, folderId)` + `_moveAfter(srcId, targetId)`
- 搜索过滤：`_matchesSearch(item, allPages)` 递归匹配（文件夹内子项匹配则文件夹保留）
- 对话框全部使用 `modal.show()` 实例方法，fallback 到 `prompt()/confirm()`
- inline rename：双击进入编辑，Enter/Escape/blur 完成

**方法清单**（~25 个）：
`render` / `_draw` / `_createToolbar` / `_createTree` / `_renderLevel` / `_createFolderRow` / `_createPageRow` / `_createEmpty` / `_getChildren` / `_matchesSearch` / `_bindContextMenu` / `_showContextMenu` / `_moveInto` / `_moveAfter` / `_promptAdd` / `_promptRename` / `_inlineRename` / `_confirmDelete` / `_triggerImport` / `_bindBusEvents` / `refresh`

### 3. ui/tabs/ai-tab.js — 多会话 + Markdown 重写

**变更**：

- 多会话管理：`conversations[]` 数组，`activeConvId` 标识当前会话
- 轻量 Markdown 渲染器 `_renderMarkdown(text)`：
  - 代码块（```lang）→ `<pre><code>` + 语言标识 + 复制按钮
  - 行内代码（`` ` ``）→ `<code>`
  - 粗体（`**text**`）→ `<strong>`
  - 标题（`#`/`##`/`###`）→ `<h3>`/`<h4>`/`<h5>`
  - 列表（`-`/`1.`）→ `<ul>`/`<ol>`
  - 引用（`>`）→ `<blockquote>`
  - HTML escape 防止 XSS
- 消息操作：`_copyMessage`、`_regenerate`、`_deleteMessage`
- 侧栏：会话列表 + "新对话"按钮 + Token 统计
- 上下文标签：选中元素/标注/变更 → chips 显示 → 可移除
- Auto-resize textarea：`input` 事件动态调 height（min 40, max 200）
- 思考动画：三点跳动 `.cc-ai-typing-dots`
- 状态监听：`state:changed` → AI 配置变更时自动重绘

**方法清单**（~23 个）：
`render` / `_draw` / `_renderSidebar` / `_renderHeader` / `_renderMessages` / `_renderMessage` / `_renderComposer` / `_renderUnconfigured` / `_renderMarkdown` / `_escapeHtml` / `_sendMessage` / `_onAIResponse` / `_copyMessage` / `_regenerate` / `_deleteMessage` / `_switchConversation` / `_newConversation` / `_clearConversation` / `_showContextChips` / `_buildFullPrompt` / `_updateTokenUsage` / `_autoResizeTextarea` / `destroy`

### 4. ui/settings-dialog.js — 修复

**问题**：`_bindTabs()` 和 `_bindFields()` 使用 `document.querySelector('.cc-overlay:last-of-type .cc-dialog-body')` 选择器不稳定。

**修复**：`open()` 方法捕获 `modal.show()` 返回的 overlay，从 overlay 中查找 `.cc-dialog-body` 传递给 bind 方法。
