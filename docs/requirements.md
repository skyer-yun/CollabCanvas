# CollabCanvas 需求文档

## 1. 产品定位

CollabCanvas 是一款面向产品经理、设计师、前端开发者的浏览器扩展工具，可将任意网页转变为可视化编辑画布，支持实时标注、AI 对话分析、多页面管理、设计审查、版本对比和协作沟通。

## 2. 目标用户

| 角色 | 核心诉求 |
|------|----------|
| 产品经理 | 在网页原型上直接标注需求、关联 PRD 字段、AI 辅助分析 |
| 设计师 | 视觉审查、标注间距/颜色/字体差异 |
| 前端开发者 | 检查元素属性、提取 Design Token、对比版本差异 |
| 测试工程师 | 标注 Bug、截图、关联问题描述 |
| 售前工程师 | 客户演示时实时标注、导出标注报告 |

## 4. 非功能需求

| 类别 | 需求 | 指标 |
|------|------|------|
| 性能 | 100 次编辑操作后无内存泄漏 | 堆内存增长 < 5MB |
| 稳定性 | shutdown 后无残留事件监听 | 0 个活跃监听器 |
| 兼容性 | Chrome 88+ / Edge 88+ | Manifest V3 |
| 可用性 | 零配置启动 | 点击图标即用 |
| 安全性 | 不硬编码密钥 | 无 API Key |
| 可靠性 | 撤销栈上限 100 步 | 防止内存溢出 |
| 体积 | 扩展包 < 500KB | 不含 html2canvas |

## 5. 约束条件

1. **零构建工具**：纯 JavaScript，不使用 Node.js / Webpack / Babel
2. **Manifest V3**：符合 Chrome Extension 最新标准
3. **最小权限**：仅申请 activeTab / downloads / scripting / storage
4. **无外部服务依赖**：所有功能本地运行，AI 为可选增强
5. **双模式运行**：Chrome Extension + 独立 HTML 页面
