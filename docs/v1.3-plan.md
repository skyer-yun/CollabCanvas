# CollabCanvas v1.3 规划 — AI 设计智能增强

## 变更日期

2026-06-03

## 背景与动机

v1.2 完成了 Pages Tab 树形重写和 AI Tab 多会话重写，CollabCanvas 已具备基础的页面管理和 AI 对话能力。

但当前 AI Tab 本质是"通用聊天窗口"——它不理解项目的设计系统，不检查输出质量，也不从已有页面中学习风格。结果是 AI 生成的 HTML 使用硬编码颜色/字号，与项目既有风格脱节。

v1.3 的目标：**让 AI 从"帮你画页面"升级为"按你的设计规范画页面"**。

灵感来源：[Axhub Make](https://axhub.im/make/) 的三个核心实践——设计质量强制系统、主题即数据、历史项目导入作为上下文。

## DS-01：AI 消费设计系统 Token

### 问题

当前 `_buildFullPrompt()` 构造的 AI 请求中不包含项目的设计系统信息。AI 返回的 HTML 使用硬编码颜色（如 `#333`、`#1677ff`）和字号（如 `14px`），无法与项目 CSS 变量体系对齐。

### 方案

在 `_buildFullPrompt()` 中注入当前项目的 CSS 变量列表，要求 AI 输出使用 `var(--cc-*)` 的 HTML。

### 详细设计

**位置**：`ui/tabs/ai-tab.js` → `_buildFullPrompt()` 方法

**新增辅助方法**：

```javascript
/**
 * 从页面样式中提取 CollabCanvas CSS 变量
 * 返回结构化的设计 Token 摘要
 */
_extractDesignTokens: function() {
  var root = document.documentElement;
  var style = getComputedStyle(root);
  var tokens = {
    colors: {},
    spacing: {},
    typography: {},
    radius: {}
  };

  // 颜色变量
  var colorVars = ['--cc-primary', '--cc-success', '--cc-warning', '--cc-danger',
                   '--cc-text', '--cc-text-secondary', '--cc-border',
                   '--cc-bg', '--cc-bg-gray'];
  colorVars.forEach(function(v) {
    var val = style.getPropertyValue(v).trim();
    if (val) tokens.colors[v] = val;
  });

  // 间距变量
  var spaceVars = ['--cc-space-xs', '--cc-space-sm', '--cc-space-md',
                   '--cc-space-lg', '--cc-space-xl'];
  spaceVars.forEach(function(v) {
    var val = style.getPropertyValue(v).trim();
    if (val) tokens.spacing[v] = val;
  });

  // 排版变量
  var typoVars = ['--cc-font-size-sm', '--cc-font-size-base', '--cc-font-size-lg',
                  '--cc-font-size-xl', '--cc-font-family', '--cc-line-height'];
  typoVars.forEach(function(v) {
    var val = style.getPropertyValue(v).trim();
    if (val) tokens.typography[v] = val;
  });

  // 圆角变量
  var radiusVars = ['--cc-radius-sm', '--cc-radius-md', '--cc-radius-lg'];
  radiusVars.forEach(function(v) {
    var val = style.getPropertyValue(v).trim();
    if (val) tokens.radius[v] = val;
  });

  return tokens;
}
```

**修改 `_buildFullPrompt()`**：在 system prompt 中追加设计 Token 指令：

  systemPrompt += '### 颜色\n';

    systemPrompt += '- ' + k + ': ' + tokens.colors[k] + '\n';
  });

  if (Object.keys(tokens.spacing).length > 0) {
    systemPrompt += '\n### 间距\n';
    Object.keys(tokens.spacing).forEach(function(k) {
      systemPrompt += '- ' + k + ': ' + tokens.spacing[k] + '\n';
    });
  }

  if (Object.keys(tokens.typography).length > 0) {
    systemPrompt += '\n### 排版\n';
    Object.keys(tokens.typography).forEach(function(k) {
      systemPrompt += '- ' + k + ': ' + tokens.typography[k] + '\n';
    });
  }

  if (Object.keys(tokens.radius).length > 0) {
    systemPrompt += '\n### 圆角\n';
    Object.keys(tokens.radius).forEach(function(k) {
      systemPrompt += '- ' + k + ': ' + tokens.radius[k] + '\n';

}

## DS-02：导入时提取设计特征

### 问题

`importPages()` 导入 HTML 文件后只存储原始 HTML，不提取其中的设计特征（色板、字号模式、间距模式）。后续 AI 生成时无法参考已导入页面的风格。

### 方案

在 `importPages()` 成功后，扫描 HTML 提取颜色/字号/间距模式，存入 `state.settings.designProfile`，作为 AI 生成的"项目风格参考"。

### 详细设计

**位置**：`main.js` → `importPages()` 方法末尾 + 新增辅助函数 `_extractDesignProfile()`

**新增状态字段**（`core/state.js`）：

```javascript
// settings 新增
designProfile: {
  colors: [],       // [{hex, count}] 使用频率排序
  fontSizes: [],    // [{size, count}]
  fontFamilies: [], // [{family, count}]
  spacing: []       // [{value, count}]
}
```

**新增辅助函数**：

```javascript
/**
 * 从 HTML 字符串中提取设计特征
 * @param {string} html - 页面 HTML
 * @returns {object} 设计特征摘要
 */
function _extractDesignProfile(html) {
  var tmp = document.createElement('div');
  tmp.innerHTML = html;
  var colors = {}, sizes = {}, families = {}, spacing = {};

  // 遍历所有有 style 的元素
  var els = tmp.querySelectorAll('[style]');
  for (var i = 0; i < els.length; i++) {
    var s = els[i].style;
    // 提取颜色
    ['color', 'backgroundColor', 'borderColor'].forEach(function(prop) {
      var v = s[prop];
      if (v && v !== '' && v !== 'transparent' && v !== 'inherit') {
        colors[v] = (colors[v] || 0) + 1;
      }
    });
    // 提取字号
    if (s.fontSize) {
      sizes[s.fontSize] = (sizes[s.fontSize] || 0) + 1;
    }
    // 提取字体
    if (s.fontFamily) {
      families[s.fontFamily] = (families[s.fontFamily] || 0) + 1;
    }
    // 提取间距（margin/padding 值）
    ['marginTop', 'marginBottom', 'paddingTop', 'paddingBottom', 'gap'].forEach(function(prop) {
      var v = s[prop];
      if (v && v !== '0px' && v !== '') {
        spacing[v] = (spacing[v] || 0) + 1;
      }
    });
  }

  // 按频率排序，取 top 8
  function topN(obj, n) {
    return Object.keys(obj)
      .sort(function(a, b) { return obj[b] - obj[a]; })
      .slice(0, n)
      .map(function(k) { return { value: k, count: obj[k] }; });
  }

  return {
    colors: topN(colors, 8),
    fontSizes: topN(sizes, 6),
    fontFamilies: topN(families, 4),
    spacing: topN(spacing, 6)
  };
}
```

## DS-03：AI 输出设计质量检查

### 问题

AI 返回的 HTML 可能仍包含硬编码值（即使 DS-01 注入了 Token 指令，AI 也不一定 100% 遵守）。需要后处理步骤检查并替换。

### 方案

在 `_onAIResponse()` 中增加后处理步骤，扫描 AI 输出中的硬编码颜色/字号，替换为最近的 CSS 变量。

### 详细设计

**位置**：`ui/tabs/ai-tab.js` → 新增 `_sanitizeDesignOutput()` 方法

**设计 Token 映射表**：

```javascript
/**
 * 设计 Token 映射：硬编码值 → CSS 变量
 * 从 getComputedStyle 动态构建
 */
_buildTokenMap: function() {
  var root = document.documentElement;
  var style = getComputedStyle(root);
  var map = { colors: {}, sizes: {} };

  // 收集所有颜色变量及其计算值
  var colorVars = ['--cc-primary', '--cc-success', '--cc-warning', '--cc-danger',
                   '--cc-text', '--cc-text-secondary', '--cc-border',
                   '--cc-bg', '--cc-bg-gray'];
  colorVars.forEach(function(v) {
    var val = style.getPropertyValue(v).trim();
    if (val) map.colors[val.toLowerCase()] = 'var(' + v + ')';
  });

  // 收集字号变量
  var sizeVars = ['--cc-font-size-sm', '--cc-font-size-base', '--cc-font-size-lg',
                  '--cc-font-size-xl'];
  sizeVars.forEach(function(v) {
    var val = style.getPropertyValue(v).trim();
    if (val) map.sizes[val] = 'var(' + v + ')';
  });

  return map;
}
```

**后处理方法**：

```javascript
/**
 * 检查并替换 AI 输出中的硬编码设计值
 * @param {string} html - AI 生成的 HTML
 * @returns {string} 清理后的 HTML
 */
_sanitizeDesignOutput: function(html) {
  var map = this._buildTokenMap();

  // 替换硬编码颜色为 CSS 变量
  // 匹配 color: #xxx / background: #xxx / border-color: #xxx 等
  Object.keys(map.colors).forEach(function(computed) {
    // computed 是 getComputedStyle 返回的 rgb() 格式
    // 先尝试匹配原始 hex 值（通过反向转换）
    var hex = this._rgbToHex(computed);
    if (hex) {
      var regex = new RegExp(hex, 'gi');
      html = html.replace(regex, map.colors[computed]);
    }
    // 也替换 rgb 格式
    var rgbRegex = new RegExp(computed.replace(/[.*+?^${}()|[\]\\]/g, '\\$&'), 'gi');
    html = html.replace(rgbRegex, map.colors[computed]);
  }.bind(this));

  // 替换硬编码字号
  Object.keys(map.sizes).forEach(function(size) {
    var regex = new RegExp(size.replace(/[.*+?^${}()|[\]\\]/g, '\\$&'), 'g');
    html = html.replace(regex, map.sizes[size]);
  });

  return html;
}

/**
 * rgb(r, g, b) → #rrggbb
 */
_rgbToHex: function(rgb) {
  var match = rgb.match(/rgb\((\d+),\s*(\d+),\s*(\d+)\)/);
  if (!match) return null;
  var r = parseInt(match[1]).toString(16).padStart(2, '0');
  var g = parseInt(match[2]).toString(16).padStart(2, '0');
  var b = parseInt(match[3]).toString(16).padStart(2, '0');
  return '#' + r + g + b;
}
```

**修改 `_onAIResponse()`**：在渲染前对代码块内容执行清理：

## 风险与缓解

| 风险 | 缓解措施 |
|------|----------|
| CSS 变量名不统一（--cc-* vs 其他前缀） | `_extractDesignTokens()` 使用 `getComputedStyle` 兜底，变量名不存在时跳过 |
| `_sanitizeDesignOutput()` 误替换代码块中的非 CSS 内容 | 限定只替换 HTML `<style>` 和 `style=""` 属性内的值，不处理纯文本 |
| 设计特征提取对大 HTML 性能影响 | 限制遍历前 500 个 `[style]` 元素，`topN` 只取前 8 |
| `importPages()` 同步提取特征可能阻塞 | 特征提取放在 `setTimeout` 异步执行，不阻塞页面切换 |
